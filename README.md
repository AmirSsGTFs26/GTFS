# GTF RTS

نسخه 0.2 از بازی استراتژی لحظه‌ای GTF.

## اجرا
فایل `index.html` را در مرورگر باز کنید. تمام assetهای مورد نیاز داخل پوشه `assets` قرار دارند و پروژه برای اجرای محلی به سرور یا اینترنت نیاز ندارد.

## امکانات فعلی
- نقشه RTS با منابع
- انتخاب و حرکت واحدها با کلیک
- ساخت واحد و ساختمان
- تنظیم سرعت بازی و نمایش شبکه
- ذخیره و بارگذاری با LocalStorage
- رابط فارسی و سازگار با موبایل
